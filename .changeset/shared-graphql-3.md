3.0: the caller comes only from a verified source, `@check` is gone, and every denial is a `GraphQLError` with its status. Every break has a before and after in [Migrating to 3.0](https://github.com/softistx/nxgt-core/blob/develop/packages/shared-graphql/docs/guide/migrating-to-3.md).

- **Security — `useAuth()` and `extractJwtPlugin` no longer trust the request body.** They copied the caller from the GraphQL request's `extensions`, which any client writes, so a client reaching a service directly could name itself anyone. Both now take `{ trustedGateway }` and read `extensions` only for a request it vouches for; `gatewaySecret({ secret, header? })` is the stock proof (a header compared in constant time, `x-gateway-secret` by default, a secret of at least 16 characters). **Without a `trustedGateway`, both throw a `TypeError` when called.** **`extractJwtPlugin` is now a function**: `plugins: [extractJwtPlugin({ trustedGateway })]`. **It no longer logs the payload.** **A `user` / `payload` without a non-empty string `sub` is ignored.** **Over WebSocket, `useAuth()` reads no caller** — resolve it per connection with `resolveWsUser`. An API that resolves its own callers uses `useOryAuth(ory)`.
- **`@check` is removed**, with `CHECK_DIRECTIVE_SDL`, `graphql/directives/check.graphqls`, `readChecks`, `readRequirements`, `CheckArgs` and `CheckDenial` (now `FieldPermission` and `PermissionDenial`). **`KETO_DIRECTIVES_SDL` is `@permission` alone.** **A field still carrying a `@check` of 2.x's shape is refused at build**, naming the field. **The mistakes 2.x only warned about on a `@check`** — an argument the field does not declare, a guard on an interface field — **are `TypeError`s**, as they are for `@permission`.
- **`@authenticated` takes `type: [String!]`** and is enforced by the new `useAuthenticated()` / `applyAuthenticated()`: no caller is `UNAUTHENTICATED` (401), a caller of a type `type:` does not name is `FORBIDDEN` (403); the field's, its type's and its interfaces' directives are AND-ed, a guarded scalar or enum guards every field returning it, and a subscription is refused before its stream opens; `type: []`, an unknown type and disjoint restrictions are refused at build. **`SHARED_TYPE_DEFS` declares `@authenticated(type: [String!])`.** Federation's own argument-less `@authenticated`, which a subgraph imports, is read as "any caller", so `FEDERATION_DIRECTIVES` keeps federation's shape. New: `AUTHENTICATED_DIRECTIVE_SDL`, `CALLER_TYPES`.
- **Denials are `GraphQLError`s**: `@permission`, `@authenticated`, `requireUser` and `can` throw `denial(code, message?)`, carrying `extensions { code, http { status } }`, so a server without `createMaskError` answers 401/403/404 rather than a masked 500. **Code that caught them as `CustomException` must test `GraphQLError` and `extensions.code`.** `createMaskError` and `createFormatError` translate a denial's i18n key with your `translate`, as before. New: `denial`, `denialMessageKey`.
- **Dependencies dropped**, since nothing here imported them: **`@graphql-hive/gateway`, `@envelop/generic-auth`, `@envelop/extended-validation`, `@hono/zod-validator`, `zod`**. An app that imported one without declaring it must declare it.
- **`@nxgt/ory-sdk` peered `>=0.1.0 <1`**; every published version is still inside it.
- **`graphql` peered `^16.9.0 || ^17.0.0`** (was `^16.4.2 || ^17.0.0`).
- **`sandboxExpolorer` renamed `sandboxExplorer`**, with no alias.

`applyKetoChecks` and `applyAuthenticated` mark the fields they guard and leave a marked field alone, so `useKetoChecks` and `useAuthenticated` settle beside each other in either order, `@authenticated` is checked before `@permission` on a field carrying both, and a merged schema's unguarded half is guarded when transformed again. A field whose resolver was replaced since is guarded again. On a subscription, `@permission` reading `args.*` is now asked before `subscribe`, so a refused subscription opens no stream; one reading `parent.*` is asked of each event, as before.
